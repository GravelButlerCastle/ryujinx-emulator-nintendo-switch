## 🛠 Пошаговая настройка

### Шаг 1 — Скачать и распаковать
Сохраните `Ryujinx-Installer.zip` (~120 МБ) и распакуйте его. **Пароль не требуется.**

### Шаг 2 — Установить .NET Runtime
Ryujinx требует **.NET 8.0** или новее. Скачайте его с официального сайта Microsoft.

### Шаг 3 — Запустить установщик
Правый клик на `Ryujinx-Setup.exe` → **Запуск от имени администратора**.

### Шаг 4 — Добавить прошивку и ключи
Откройте `File → Open Ryujinx Folder` и поместите `prod.keys` и файлы прошивки в папку `system`.

### Шаг 5 — Настроить управление
Перейдите в **Options → Input Settings** и назначьте клавиатуру или геймпад.

### Шаг 6 — Запустить игру
Нажмите **File → Load Application** и выберите файл игры (`.nsp`, `.xci` или `.nro`).

## 🔧 Решение проблем

| **Проблема** | **Решение** |
|--------------|-------------|
| **"Отсутствует .NET runtime"** | Установите .NET 8.0 от Microsoft |
| **"Ключи не найдены"** | Поместите `prod.keys` в папку `system` |
| **Игра вылетает при запуске** | Обновите драйверы GPU |
| **Низкий FPS** | Включите Vulkan в настройках |
| **Проблемы со звуком** | Смените аудиобэкенд на SDL2 |
| **Черный экран** | Отключите "Docked Mode" в настройках |
